Renders the layout grid of Form Schema §5.5: forms that set a `width` on any element lay out pages, panels and repeater items on a grid of `settings.layout.columns` columns, in document order. Inactive elements and hidden fields take no space. Below 36rem of viewport width (or of a host element declared as `container: fk / inline-size`) every element takes a full row. Forms without widths render exactly as before.
