`@formkiln/react`: add `<KilnForm />`, `useKilnForm` and `useFormState`. Built on React Aria Components: default fields for text, email, phone, URL, textarea, number, radio, select, checkboxes, boolean (checkbox, switch, yes/no), date, time and date-time; panels and plain content; paged and single navigation with progress; an error summary that receives focus and links to fields; localised interface strings (English, Simplified Chinese); replaceable field components; and an optional theme (`@formkiln/react/styles.css`) based on CSS custom properties, with dark mode.

`@formkiln/core`: the form controller gains `isRequired(path)` and `isReadOnly(path)`.
